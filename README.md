# 初中数学知识框架 · 点击刷题系统

![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)
![前端](https://img.shields.io/badge/前端-单文件%20HTML-blue)
![构建](https://img.shields.io/badge/构建-零依赖-brightgreen)

一个**纯静态**的初中数学刷题网站：一个 HTML 文件 + 一个题库文件，**双击就能打开，不需要服务器、不需要后端、不需要 npm install**。

按人教版教材（七上—九下）组织 29 个核心概念，支持四级跳转刷题：

```
简略版词条 → 概念详解 → 题型 → 难度（简单/中等/较难/难）→ 习题与答案
```

- 🔗 在线体验：https://longzqh319774.github.io/junior-math-trainer/
  （首次部署后生效；若 GitHub 用户名不是 `longzqh319774`，把上面链接里的用户名改掉即可）

## 一、快速开始

### 什么都不装，先看看效果

1. 下载或克隆本仓库
2. 双击打开 `site/index.html`

此时用的是仓库自带的**示例题库**（45 道自编通用例题），四级跳转全部可正常体验。

### 导入自己的题源

```bash
# 1. 把试卷放进 papers/（也可用 --src 指向别的目录）
#    文件名建议含年份，如「2024天津数学试卷.docx」

# 2. Word 试卷 → 抽取题目与配图 → 生成原始 JSON
python tools/import_docx.py

# 3. 合并所有原始 JSON → 生成前端题库
python tools/build_data_js.py

# 4. 再次打开 site/index.html，顶部会显示你自己的题量
```

只处理 Word 试卷时**无需安装任何依赖**（`import_docx.py` 只用标准库）。
处理 PDF 才需要：

```bash
pip install -r requirements.txt
```

## 二、题源导入的三种路径

| 你的材料 | 用什么工具 | 说明 |
|---|---|---|
| Word(.docx) 试卷 | `tools/import_docx.py` | 自动抽题、按 29 个概念分类、导出配图 |
| PDF（有文本层） | `tools/ocr_pdf.py` + `tools/crop_figs.py` | 先抽文本，整理成 JSON 后裁剪配图 |
| PDF（扫描版/图片） | `tools/ocr_pdf.py` + `tools/crop_figs_scan.py` | 先 OCR，再定位非文字墨迹区域裁剪配图 |

配图清单：扫描卷 OCR 常把"如图"字样丢掉，此时在 `data/figure_need.json` 手工指定：

```json
{ "2023": [3, 10, 11, 17], "2024": [2, 10, 11, 17] }
```

## 三、原始题库格式

原始 JSON 放在 `data/raw/` 下，是**一个数组**，每项为一道题：

```json
[
  {
    "y": 2024,
    "n": 1,
    "src": "2024·天津中考 第1题",
    "c": "有理数",
    "t": "相反数",
    "d": "简单",
    "q": "-2的相反数是( )\nA. 2    B. -2    C. 1/2    D. -1/2",
    "a": "A。只有符号不同的两个数互为相反数。",
    "imgs": ["img/y2024_q1.png"]
  }
]
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `c` | ✅ | 概念，必须是下方 29 个之一 |
| `t` | ✅ | 题型，简短中文，如「科学记数法」「二次函数压轴」 |
| `d` | ✅ | 难度，只能是 `简单` `中等` `较难` `难` |
| `q` | ✅ | 题干。数学符号用纯文本（√、²、×、÷、π、°、∠、△、∽、≌、∥、≥、≤） |
| `a` | ⭕ | 答案与一句话思路，可留空 |
| `imgs` | ⭕ | 配图路径数组，相对 `site/` 目录 |

**29 个合法概念名**（`c` 的取值，必须完全一致）：

```
有理数  实数  整式  因式分解  分式  二次根式  一元一次方程  二元一次方程组
不等式与不等式组  一元二次方程  分式方程  平面直角坐标系  一次函数  反比例函数
二次函数  线与角  相交线与平行线  三角形  全等三角形  轴对称与等腰三角形
勾股定理  平行四边形与特殊四边形  旋转与中心对称  相似三角形  锐角三角函数
圆  投影与视图  统计  概率
```

## 四、⚠️ 数据与版权说明（请务必阅读）

本项目采用**代码与数据分离**的设计：

- ✅ 仓库包含：前端代码、概念知识框架、导入工具、自编示例题库
- ❌ 仓库不含：任何真题、教辅题目、答案与配图（已被 `.gitignore` 排除）

**原因**：中考真题与商业教辅（各类同步练习册、总复习资料）的著作权归原权利人所有，把它们的原文与图片上传到公开仓库，属于未经授权的复制与传播。

因此：

1. 请勿向本仓库提交真题 / 教辅原题内容，此类 PR 会被直接关闭
2. 导入题源请使用你有权使用的材料（自编题、已获授权的试卷、开放授权题源）
3. 脚本生成的 `site/data.js` 与 `site/img/` **不会**被提交，只留在你本地
4. 要在网上公开部署时，请只部署不含你自己题源的仓库副本

> 简言之：**项目开源，你的题库不上云。**

├── logs/                     运行日志（不入库）

## 六、部署到 GitHub Pages

1. 把仓库推送到 GitHub
2. 仓库 Settings → Pages → **Source** 选 `GitHub Actions`
3. 推送到 `main` 分支后自动部署，Actions 里能看到进度

工作流只上传 `site/` 目录，你的试卷与题库不会被带上。

## 七、常见问题

**Q：页面显示"示例题库"，我的题呢？**
A：先运行 `tools/build_data_js.py` 生成 `site/data.js`。浏览器会优先加载 `data.js`，存在时自动切换；不存在时回退到示例题库并在控制台给出提示。

**Q：导入的题目没有配图？**
A：需要先用 `crop_figs.py` / `crop_figs_scan.py` 裁图，并把 `imgs` 写进原始 JSON，再重新 `build_data_js.py`。

**Q：题目显示不全，选项后半截没了？**
A：这是个已知坑，已在前端修好：题干含 `<` `>` 等符号时统一做了 HTML 转义。若你二次开发，注入文本时务必转义。

**Q：概念分类不准？**
A：`import_docx.py` 用关键字匹配，命中率约 75%。可直接编辑 `data/raw/*.json` 里的 `c`、`t` 字段手工校正，改完重新生成即可。

**Q：怎么改成别的教材版本（北师大、苏科等）？**
A：改 `site/index.html` 里的 `CONCEPTS` 与 `SEMESTERS` 两个常量即可，概念名与原始 JSON 的 `c` 保持一致就行。
